ESP32-S3 ChocolatePlus Bridge — Flash tool

Flashes the firmware that turns a cheap ESP32-S3 "pocket dongle" into a USB-MIDI ↔ BLE bridge between an MVave Chocolate Plus MIDI pedal and a Positive Grid Spark GO amp. Straight from this page, no software to install. See the project README for what the dongle actually does, the MIDI mapping, and hardware details.

No support provided. This is a personal/community project, shared as-is. If something doesn't work, the README and PROTOCOL.md have the technical details, but there's no guarantee of help beyond that. Flash at your own risk.
Only works in Chrome, Edge, or Opera on a computer (Windows, macOS, Linux, or ChromeOS) - it needs the Web Serial API, which Firefox, Safari, and mobile browsers don't support.
Before you click Connect:
  1. Plug the dongle into your computer's USB port.
  2. This specific board has no separate reset circuit, so you need to put it into flashing mode by hand: hold down the BOOT button on the dongle while you do step 1 (or unplug/replug it while holding BOOT), then keep holding it for a couple of seconds after it's plugged in before releasing.
  3. Click "Connect" below and pick the dongle's port when the browser asks.
If the browser doesn't show a port to pick, redo the BOOT-button step and try again.
Your browser doesn't support Web Serial - open this page in Chrome or Edge on a computer instead. This page needs to be served over HTTPS to flash a device - if you're seeing this on the real site, something's wrong; please report it.

After flashing, the dongle needs to be plugged into the Chocolate Plus's USB HOST port (not a regular computer) to actually work as a bridge, and the pedal's footswitches need to be programmed via MVave's CubeSuite app - see the README linked above for the exact MIDI mapping.
